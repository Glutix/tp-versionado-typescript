# TP Gestión de Versionado del Software

Proyecto individual correspondiente al Trabajo Práctico Nº4 --- Gestión de Versionado del Software.

## Descripción

Aplicación sencilla desarrollada en TypeScript para gestionar una lista de tareas mediante consola.

## Tecnologías

- TypeScript
- Node.js
- Git
- GitHub

## Ejecución

Instalar las dependencias:

```bash
npm install
```
